# Dependency upgrade: gpui-kit 0.7.3 → 0.8.0 (2026-10-25)

**Machine:** local (Apple M1, Darwin 25.6.0). **Machine load:** 11.3 at the first `check`, 2.6–5 through the suites and the A/Bs (other work on the machine), so TTFP is compared interleaved against a 0.7.3 build, not against the baseline.

**What changed:** `gpui-kit =0.8.0`, `Cargo.lock` re-seeded from 0.8.0's published lock: gpui-kit/gpui-component/gpui-base/gpui-kit-assets 0.8.0, gpui-pre-* still 0.3.9 (the default backend; gpui-fast, unused, 0.1.8 → 0.1.10), **wasm-bindgen 0.2.121 → 0.2.127** (js-sys/web-sys 0.3.104), so `wasm-bindgen-cli` 0.2.127. `atoi`, the one workspace dependency outside gpui-kit's lock that floated on `cargo fetch` (3.1.0 → 3.1.1), was pinned back. No code changes: every crate built and passed clippy without warnings. JS dependencies unchanged.

**Files:**
- `2026-10-25-gpui-kit-0.8.0-ab.json`: `just tycho placeholder --ab` against a HEAD (0.7.3) build from a worktree with its own `target/`, 10 interleaved runs per build, reference and throttled; also the placeholder checks on 0.8.0. The third of three runs (below).
- `2026-10-25-gpui-kit-0.8.0-table.json`: `just tycho table --reference-only`, asteroids, n=10.
- `2026-10-25-gpui-kit-0.8.0-jump.json`: `just tycho jump --reference-only`, asteroids + Gaia, n=10, with the input's edge checks.
- `raw/2026-10-25-gpui-kit-0.8.0-{sample,cells,errors,panel,drop,csv}.json` and `raw/2026-10-25-gpui-kit-0.8.0-suites.log`: those six suites, run under their default labels (which name the milestone that built each) and moved to `raw/`, so `report` doesn't take them as the docs' numbers.

## Numbers

| | 0.7.3 (HEAD) | 0.8.0 |
|---|---|---|
| App wasm (brotli) | 2844.6 KiB | **2855.6 KiB (+11.0 KiB, +0.4%)** |
| Reference TTFP, interleaved A/B (n=10) | 193.2 ms | 193.4 ms (+0.1%) |
| Throttled TTFP, interleaved A/B (n=10) | 3734.9 ms | 3746.9 ms (+0.3%) |

The reference A/B didn't meet its 6% spread gate in three runs, each failed by one outlier, on a different side each time: 0.7.3 23.2% / 0.8.0 10.0% (load 7.7), 10.5% / 2.8% (load 3.6; medians 196.9 vs 194.8), 5.2% / 15.7% (load 2.6; the medians in the table below). The throttled side passed every time (spread ≤ 1.4%, 0.8.0 +0.3–0.5%). Read it as TTFP unchanged, not proven to 3%; rerun `placeholder --ab` on a quiet machine to close it.

`just tycho check`: 209.1 ms vs the 214.8 ms limit (load 11.3 at its start), 2855.6 KiB vs 3247.1 KiB. PASS.

The other builds of the gpui family: the observatory's GPUI contender 2697.8 → 2707.9 KiB (+10.1), the tall table's bare host 2677.7 → 2689.3 KiB (+11.6); their notes are `apps/observatory/perf/results/2026-10-25-gpui-kit-0.8.0.md` and `components/tall-table/perf/results/2026-10-25-gpui-kit-0.8.0.md`. Where the ~11 KiB went wasn't broken down; 0.8.0's changes that reach a wasm build without new features are the scroll-bounce engine behind every scrollable, the Root's focus-trap rework, and the input's wrapping and caret fixes.

## Functional checks

- First-frame probe: the mark followed the presenting GPU task in every `perf.ts` run on 0.8.0 (WebGPU). gpui-pre-web is unchanged (0.3.9).
- Table (`table --reference-only`): first rows 203.7 ms, jump to 90% 81.3 ms, fling p95 **16.7 ms**, max 16.7–33.3 ms, 0 frames over 50 ms, work p50 5.9 / p95 7.7 ms, steady p95 16.7 ms, last row matches. PASS.
- Jump to row, both samples: all jumps and refusals pass; IME, Ctrl/Cmd+V, context-menu Paste with `clipboard-read` lands, without it nothing is pasted (unchanged, as the root CLAUDE.md says); the Mac keys pass. PASS.
- Placeholder vs first frame (light/dark, DPR 2 and 1), the theme toggle, sample, cells, errors (every case ok), panel (17/17 values match), drop (drop and file dialog in Chromium, Firefox, WebKit), csv (counts, extent, and last row in every browser): PASS.
- Still true on 0.8.0 (source checked): Input binds its Mac shortcuts only under `cfg(target_os = "macos")`, so `shared/`'s bootstrap still binds them; gpui-pre-web (unchanged) still `preventDefault`s and drops `dragover`/`drop`; the default theme (`default-theme.json`), `skeleton.rs`, the title bar, and gpui-kit-assets (the Sun/Moon icons) are unchanged, so `placeholder.ts` needed no change, and the observatory's generated `theme.css` changed only in its version line. `Button`'s hover now registers on every render (a stale-hover fix), the same colors.
- 0.8.0's breaking changes don't reach this repo's code: nothing uses `gpui-wry`, `SelectionFormat`, `TabVariant`, `ResizeHandle`, `Easing::sample`, `DataTable`, or `ScrollBounce`; the tall table owns its scrolling.
- Not run: `engine`, `smoke` (a running dev server), the throttled table and jump. Manual pass in real Firefox and Safari not done.

## Reproducing it

```sh
just tycho check
just tycho table --reference-only --label gpui-kit-0.8.0-table
just tycho jump --reference-only --label gpui-kit-0.8.0-jump
just tycho placeholder --ab <HEAD build's web/dist> --label gpui-kit-0.8.0-ab
```
