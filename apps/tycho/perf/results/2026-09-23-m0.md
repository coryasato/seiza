## Cross-browser smoke (`just tycho smoke`)

Headless Playwright browsers at 1440×900, one cold run each against the release build (`just tycho preview`). The script resizes through 1440×900 → 1024×700 → 640×480 → 1600×1000 → 1440×900. After each resize it checks that the frame is painted edge to edge, the canvas's CSS box matches the viewport, and the backing store kept its backing/CSS ratio.

| Browser | DPR | Backing ratio | Painted | `crossOriginIsolated` | Console errors | Blank frames | Size mismatches | first-frame mark (1 run) |
|---|---|---|---|---|---|---|---|---|
| Chromium | 1 | 1× | yes | true | 0 | 0 | 0 | 1147 ms |
| Firefox | 2 (`devPixelsPerPx`) | 2× | yes | true | 0 | 0 | 0 | 595 ms |
| WebKit | 2 | 2× | yes | true | 0 | 0 | 0 | 437 ms |

**Negative control:** with the canvas pinned at 1440×900 CSS px (so it can't shrink or grow), the same script fails in every engine with 3 size mismatches and 1 blank frame.

**Why Chromium runs at DPR 1:** headless Chromium can't give GPUI a consistent DPR 2. With `deviceScaleFactor: 2` (old and new headless), `devicePixelRatio` is 2, but the canvas's `device-pixel-content-box` reports CSS pixels. gpui-pre-web sizes the backing store from that box, so it draws 2× layout into a 1× backing store: blurry, with every element twice its size. With `--force-device-scale-factor=2` it's the reverse: DPR reads 1 and the box reads 2×. Firefox has the same problem through Playwright's `deviceScaleFactor` (DPR resets to 1 after `setViewportSize`), but the `layout.css.devPixelsPerPx` pref is consistent. This is an emulation artifact: real HiDPI browsers report both correctly, as the manual check showed. **It blocks M1's reference run as written (headless Chromium, DPR 2) and is logged there as a pending decision.**

**Limits of the blank-frame check:** screenshots show a settled frame, so they can't see a transient frame during a live drag. `gpui_web` rules those out itself: its `ResizeObserver` callback runs after layout and before the browser paints, and renders synchronously with `force_render` (`gpui-pre-web` 0.3.5, `window.rs`).
