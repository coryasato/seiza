## Fling with the panel open and closed (medians of 10)

| | Interval p95 / worst | Work p50 / p95 |
|---|---|---|
| Reference, panel closed | 16.7 / 16.7 ms | 5.2 / 7.3 ms |
| Reference, panel open | 16.7 / 16.7 ms | 5.9 / 8.1 ms |
| Throttled, panel closed | 16.7 / 33.3 ms | 21.0 / 26.4 ms |
| Throttled, panel open | 16.7 / 33.3 ms | 23.8 / 29.8 ms |

The M4 budget (p95 ≤ 20 ms, none > 50 ms) holds both ways. Watching costs ~0.7 ms of work a drawn frame (reference), ~13%. Cached panel frames replay its drawing; what's left is the 4 Hz refresh frames and the per-frame timing.

**Steady scroll** (~900 px per 16 ms, mostly loaded rows): work p50/p95 **12.7 / 15.1 ms** reference, 36.9 / 42.8 ms throttled. A fling (mostly placeholder rows) is 5.2 / 7.3. Frames of loaded rows cost ~2.4× those of placeholders. The likely cause is the per-frame cell formatting M4's note warned about, but it isn't isolated yet. The interval is 16.7 ms in both cases, and only the work time shows that steady scrolling leaves ~1.6 ms of headroom at p95. Part B decides the cell-string cache from this, on Gaia too.

**Throttled work vs interval:** at CPU 4×, work per drawn frame is ~4× the reference (21 vs 5.2 ms), yet the rAF interval p95 stays 16.7 ms. Read throttled work times against each other, not against the 16.7 ms frame.
