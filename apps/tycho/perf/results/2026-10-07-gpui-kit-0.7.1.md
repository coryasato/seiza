# Dependency upgrade: gpui-kit 0.6.4 → 0.7.1 (2026-10-07)

**Machine:** local (Apple M1, Darwin 25.6.0). **Machine load:** 2.7–8.2 throughout (other work on the machine), so before and after were interleaved rather than compared to the 2026-09-23 baseline.

**What changed:** `gpui-kit =0.7.1`, `Cargo.lock` re-seeded from 0.7.1's published lock (gpui-kit/gpui-component/gpui-base 0.7.1, gpui-pre-* 0.3.8; wasm-bindgen stays 0.2.121, so `wasm-bindgen-cli` doesn't change). `shared/` now opens the window with `gpui_kit::open_window`, and `AppShell` no longer renders the overlay layers: 0.7's `Root` hosts them. JS: wrangler 4.139.0 → 4.148.0, workers-types → 5.20261007.1, vite 8.3.0 → 8.3.3, @types/node 26.6.2 → 26.6.4. DuckDB-Wasm stays 1.32.0 (the newest stable release; later builds are `-dev`).

**Files:**
- `2026-10-07-gpui-kit-0.6.4.json`, `2026-10-07-gpui-kit-0.7.1.json`: `perf.ts`, reference and throttled, n=10 each, master vs the upgrade, minutes apart.
- `2026-10-07-gpui-kit-0.7.1-ab.json`: the interleaved A/B (2 rounds × 10 reference runs per build, order after, before, after, before), every run's TTFP.
- `2026-10-07-gpui-kit-0.7.1-m4-table.json`: the full table suite (`just tycho table`: reference and throttled, n=10, plus browsers).
- `2026-10-07-gpui-kit-0.7.1-{engine,m5-drop,m6-csv}.json`: functional regression guards (`engine --runs 1`, `drop`/`csv --only browsers --reference-only`).

Medians of 10. The first pair ran minutes apart under changing load; the interleaved rounds (after, before, after, before) show no TTFP difference. `just tycho check`: 186.5 ms vs the 195.0 ms limit, 2704.4 KiB vs 3012.4 KiB. PASS. Total wasm vs the M1 baseline (2619.5 KiB): +3.2%.

Where the 31 KiB went wasn't broken down. 0.7 moves overlay hosting, keyboard traversal, and selection copying into Base's `Root` and registers per-window presentation for every component, so code that used to be dropped is now linked whether or not the app opens a dialog. The 0.6 manual layer rendering cost 26.4 KiB (M0).

## Functional checks

- First-frame probe: the mark followed the presenting GPU task in all 40 `perf.ts` runs on 0.7.1 (WebGPU). gpui-pre-web's `ResizeObserver`/`force_render` path is unchanged from 0.3.5 to 0.3.8 (diffed).
- Table, full suite (`just tycho table`): reference first rows 198.5 ms, jump to 90% 84.0 ms, fling p95 **16.7 ms**, worst **16.7 ms**, 0 frames over 50 ms, steady p95 16.7 ms, last row matches. Throttled: fling p95 16.7, worst 33.3 ms (M5's throttled no-load fling: same). Chromium, Firefox, WebKit pass. PASS.
- Engine, Parquet drop and file dialog, CSV fixture: all pass, `failures: []`.
- Dialogs and notifications under 0.7's `Root` (M0's check, repeated): a temporary `after_first_paint` that pushed a notification and opened a dialog showed both, drawn over the workbench, in Chromium (WebGPU), Firefox (WebGL2), and WebKit, with no console errors. Reverted after.
- File drops: gpui-pre-web 0.3.8 still `preventDefault`s and drops `dragover`/`drop` on the canvas, so `files.rs`'s window listener is still needed.
- Not checked: Input's context-menu Paste (#3244; Tycho has no text input until M7). Manual pass in real Firefox and Safari not done.
