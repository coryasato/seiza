# Dependency upgrade: gpui-kit 0.7.1 → 0.7.3 (2026-10-12)

**Machine:** local (Apple M1, Darwin 25.6.0). **Machine load:** 9.4 at the first `check`, 3.1–5.0 through the suites and the A/B (other work on the machine), so TTFP is compared interleaved against HEAD, not against the baseline.

**What changed:** `gpui-kit =0.7.3`, `Cargo.lock` re-seeded from 0.7.3's published lock (gpui-kit/gpui-component/gpui-base 0.7.3, gpui-pre-* 0.3.9; wasm-bindgen stays 0.2.121, so `wasm-bindgen-cli` doesn't change). 0.7.2 was yanked; 0.7.3 contains it. No code changes: Tycho and `shared/` built without warnings. JS dependencies unchanged.

**Files:**
- `2026-10-12-gpui-kit-0.7.3-ab.json`: `just tycho placeholder --ab` against a HEAD (0.7.1) build from a worktree with its own `target/` (wasm hashes differ), 10 interleaved runs per build, reference and throttled; also the placeholder checks on 0.7.3.
- `2026-10-12-gpui-kit-0.7.3-table.json`: `just tycho table --reference-only`, asteroids, n=10.
- `2026-10-12-gpui-kit-0.7.3-jump.json`: `just tycho jump --reference-only`, asteroids + Gaia, n=10, with the input's edge checks.
- `raw/2026-10-12-gpui-kit-0.7.3-suites.log`: console output of `placeholder`, `sample`, `errors`, `cells`, `table`, and `smoke`. Their JSONs went to one shared label and overwrote each other; only the table's survived. All six printed PASS.

`just tycho check`: 203.8 ms vs the 214.8 ms limit (load 9.4 at its start), 2837.3 KiB vs 3247.1 KiB. PASS. Where the 12.9 KiB went wasn't broken down; 0.7.3 adds per-frame "unchanged" checks to selection, `Root`, inputs, and resizable panels, and the input context-menu rework.

## Functional checks

- First-frame probe: the mark followed the presenting GPU task in every `perf.ts` run on 0.7.3 (WebGPU). gpui-pre-web 0.3.8 → 0.3.9 adds only display stubs (`refresh_interval`, `on_display(s)_changed`) and swaps the HTTP body channel (diffed).
- Table (`table --reference-only`): first rows 214.4 ms, jump to 90% 82.2 ms, fling p95 **16.7 ms**, max 16.7 ms (one run 33.3), 0 frames over 50 ms, work p50 5.8 / p95 7.7 ms, steady p95 16.7 ms, last row matches. PASS.
- Jump to row, both samples: all jumps and refusals pass; IME, Ctrl/Cmd+V, context-menu Paste with `clipboard-read` lands, without it nothing is pasted (unchanged, as the root CLAUDE.md says); Cmd/Ctrl+A/C/Z and the Mac word/line keys pass. Input's context menu changed upstream (#3382, #3433: builders run after the input is released); `edit_menu` needed nothing.
- Placeholder vs first frame (light/dark, DPR 2 and 1), theme toggle, sample, error states, cells: PASS. Smoke (`preview`): Chromium, Firefox (WebGL2), WebKit paint, cross-origin isolated, no console errors.
- Still true on 0.7.3 (source checked): Input binds its Mac shortcuts only under `cfg(target_os = "macos")`, so `shared/`'s bootstrap still binds them; gpui-pre-web still `preventDefault`s and drops `dragover`/`drop`; nothing binds Tab outside `DataTable`; the default theme, `skeleton.rs`, and the Sun/Moon icons are unchanged, so `placeholder.ts` needed no change.
- Not run: `drop`, `csv`, `engine`, `panel`, the throttled table and jump. Manual pass in real Firefox and Safari not done.

## Harness note

`wrangler dev` refused to start after a fresh `just tycho build` ("Asset too large", DuckDB's 33 MiB wasm): `dist/.assetsignore` is written only by `worker/scripts/deploy.ts`, and Vite empties `dist/`. Written by hand into `dist/` for these runs. Not caused by the upgrade.

## Reproducing it

```sh
just tycho check
just tycho table --reference-only --label gpui-kit-0.7.3-table
just tycho jump --reference-only --label gpui-kit-0.7.3-jump
just tycho placeholder --ab <HEAD build's web/dist> --label gpui-kit-0.7.3-ab
```
