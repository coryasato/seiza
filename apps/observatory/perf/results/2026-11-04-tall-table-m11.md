# tall-table M11: the cells' text from one element, the GPUI contender's wasm (2026-11-04)

Measured on Apple M1, Darwin 25.6.0 arm64, machine `local`: `just observatory gpui-build` and `gpui-build wide`, on `15ed4dc` with `components/tall-table/src` checked out at M11's parent (`d96547f`), then on `15ed4dc` itself. One build each; sizes from `shared-web/scripts/asset-sizes.ts`.

## What changed

The tall table's base draws each region's loaded cells' text from one element, every glyph in one layer, where it drew a `div` a cell (the table's [`perf/results/2026-11-04-m11-c.md`](../../../../components/tall-table/perf/results/2026-11-04-m11-c.md)). Nothing in the contender changed; every level gets it by building the table.
