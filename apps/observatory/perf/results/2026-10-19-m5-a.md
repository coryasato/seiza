# M5 part A: the page in the site's shell, the contenders at their own bases (2026-10-19)

Measured on Apple M1, Darwin 25.6.0, machine `local`, Chromium headless=new, 1440×900 at DPR 2, median of 10, reference and throttled (root CLAUDE.md, "Measurement protocol"). Load average 3.6–3.9 throughout (other work on the machine).

Raw: `2026-10-19-m5-a-page.json` (`just observatory page --label m5-a-page --write-baseline`: the page's cold runs and its hosting checks, the baseline).

## What changed

- **The page** (`web/`): one prerendered HTML file per route, in `site/ui`'s shell, hydrated by React; the contender's frame and the metrics module after its first paint.
- **The contenders' bases** moved to `/observatory/contenders/tall-table/<stack>/`; the engine stays at `/observatory/duckdb/`, the data at `/observatory/data/`, the font moved to `/fonts/` (the same bytes, no longer content-hashed per build).
- **The page's theme** reaches both contenders (`?theme=`, then by message). GPUI's wasm 2695.4 → 2696.6 KiB brotli; the TanStack contender's first-paint JS 72.1 → 72.3 KiB. Tycho: `apps/tycho/perf/results/2026-10-19-observatory-m5-a.md`.

## Experiments and controls

- **What the page's first paint waits for:** 5 runs each, reference, on a loaded machine: as built 74–102 ms; the entry JS held back 63–82; the font held back too 57–82; the CSS dropped 45–54 (one 297 outlier). The CSS arrives by ~27 ms; the rest is the browser laying out and painting the whole route. Neither the JS nor the font holds it back. Recorded, not chased: the page's numbers are footnotes beside the contenders'.
- **Grays control** (`web/scripts/grays.ts`, every lint): the site's light muted foreground 0.03 lighter is ΔE 3.05, over the 2.5 tolerance: it fails.
- **The hosting checks** (`perf/page.ts`): the GPUI canvas's mean brightness 244 → 22 after the toggle, in the same frame (`timeOrigin` unchanged), so the live theme isn't a reload.
