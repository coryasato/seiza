# M12 part B2: the fonts path and the capabilities' check (2026-11-09)

Measured on Apple M1, Darwin 25.6.0 arm64, machine `local`: each wasm after wasm-opt, brotli 11 (window 24), before (HEAD `e6c0a10`) and after; the GPUI contender's base build's cold check (`cold --level base --check`, reference, median of 10); `perf/admin.ts` once on both contenders' base builds (Playwright 1.63.0's Chromium 153.0.8010.12, headless, 1440×900 at DPR 2, light theme). Versions: gpui-kit 0.9.0, React 19.3.1, TanStack Virtual 3.14.19, Arrow 17.0.0, DuckDB-Wasm 1.32.0. Load average not recorded. Nothing here is a protocol run but the cold check: fonts in → drawn is one run.

Raw: `2026-11-09-m12-b2-admin.json` (`perf/admin.ts --label m12-b2-admin`: every check's numbers, both sides). These are the builds after the code review's fixes; the shapes before them are recorded below where their numbers taught something.

## What changed

- **`shared/`:** `Bootstrap::canvas_font_fallback` behind a new feature, `canvas-font-fallback`, a thread-local the bootstrap's `web_application` reads, all of it below every line an app without the feature builds ([root `docs/DECISIONS.md`](../../../../docs/DECISIONS.md), "Shell and input", 2026-11-09).
- **The GPUI contender:** the crate's feature `fonts` (`seiza`'s `canvas-font-fallback`), which only the base build turns on (`contenders/level.ts`'s `gpuiCargoFeatures`, the recipes, `sizes`, `gpui-parts`): `src/fonts.rs` (`scriptFonts(mark)`, the toggle on before `start`: `EmojiAndCjk` and the mark's name; `addFonts`, the faces added and the window refreshed; the mark from the host's next render, right after its frame), all of it at the end of `lib.rs` and `contract.rs`, and `host.rs`'s call on the line it was. The JS host's base-level host `web/src/base.ts` (the admin table with `?fonts` only) and `web/src/fonts.ts` (a chunk loaded at the first `contender:filled`: the 13 faces fetched at once and each checked against its pin, `contender:fonts-in`, then `addFonts`; a fetch or a pin failing marks `contender:fonts-failed`).
- **The faces:** `contenders/fonts/faces.ts` pins 13 Noto faces (notofonts.github.io at `4cf78353`, 2026-11-09; each version, byte count, and SHA-256), `fetch.ts` (`just observatory script-fonts`, run by what serves or checks them: the base's `gpui-dev` and `gpui-preview`, `admin`, `check`, `deploy`) fetches and checks them into `contenders/fonts/faces/` (gitignored), removing anything else, with `OFL.txt` (the 13 copyright lines, then the OFL 1.1; the fetch checks each face's name-table copyright line is in it). Each is kept and served as `<family>-Regular-<version>-<hash>.ttf` at `/observatory/fonts/` (`paths.ts`'s `SCRIPT_FONTS`) in the GPUI base build's dev and preview (`contenders/engine.ts`) and staged by the deploy, which refuses a `faces/` holding anything no pin names; immutable.
- **The contract:** `contender:fonts-in`, `contender:fonts`, `contender:fonts-failed` (`contenders/contract.ts`'s `MARKS`, `FONTS_PARAM`; `docs/contender-contract.md`).
- **`perf/admin.ts`**, in `check`, and the README's font credits.

Neither is in another level's build.

**The other levels, the first shape:** with `canvas-font-fallback` on at every level (+29 to +49 B raw), their brotli moved by −994 to +270 B. With the feature the base's alone, and the base's code placed at the end of `lib.rs` and `contract.rs`, they matched HEAD's bytes; before that placement they were 12 B larger, the same panic locations' lesson as Tycho's. The TanStack contender's first-paint JS is 73.8 KiB as before (`MARKS` grew three names).

**Tycho, the first shape:** a feature-gated builder field (and the method above `run`) left Tycho's code unchanged, but moved three panic locations' line numbers in `bootstrap.rs` by 23: 3 bytes in the wasm, and **+2,104 B brotli**. Moving the setting into a thread-local and the feature's code to the file's end gave the identical file.

## The capabilities, as `perf/admin.ts` proves them

| Capability | TanStack | GPUI | Control (both sides) |
|---|---|---|---|
| Ctrl+F "Ísland" | `window.find` finds it, in Iceland's row (row 102) | not found | DOM text found; a word not in the file isn't |
| Select and copy "Reykjavík" | the drag selects exactly it; Cmd+C puts it on the clipboard | nothing selected; the clipboard as it was | a drag selects DOM text |
| A screen reader | a `table`, 251 `row`s, 5 `columnheader`s, 1,250 `cell`s, `aria-rowcount` 251, rows indexed 2–251, Iceland's cells named | no node named by any of the file's 615 texts | DOM text named |
| Every script drawn | each script's name in a system face (Geeza Pro, Kohinoor Bangla, Kailasa, Hiragino Sans, …), none in IBM Plex Sans alone | by default none of 15 (each notdef boxes); with `?fonts` all 15 | unassigned code points: IBM Plex Sans alone (its notdef); GPUI's Latin row matches by default; with fonts no name matches another script's drawing |
| The flags | in color (spread 195) | in color (195) | a text cell's gray (0, 13) |
| Translate's precondition | every name, English name, and capital in `innerText`; nothing `translate="no"` | none of them in `innerText` | DOM text in it |
| The drawn text | cells.json's 220 admin table cells, as its shown text | (the cell fixture's own check) | the fixture read as Latin-1 differs (83 cells) |

**`window.find` doesn't scroll to its match** in headless Chromium: it selects Ísland in row 102 and the scroller stays at 0 (a `scrollIntoView` of the same node does scroll it). A1's "the row lands in view" was the find bar's behavior, not `window.find`'s, so the script checks the row and the landing stays in the manual check.

## What stays manual

The cross-browser check (Firefox, Safari): the find bar landing on Iceland's row on TanStack and finding nothing on GPUI; VoiceOver through a row in Safari; Chrome's Translate on both; the flags and the scripts with fonts in Firefox's WebGL2 and Safari.

## Reproducing it

```sh
just observatory script-fonts                 # the faces, checked against their pins
just observatory gpui-build && just observatory tanstack-build
node apps/observatory/perf/admin.ts --label m12-b2-admin   # --shots <dir> for each script's crop
node apps/observatory/perf/sizes.ts --check && node apps/observatory/perf/cold.ts --level base --check
just tycho wasm release && cmp <before>/tycho_bg.wasm apps/tycho/web/pkg/tycho_bg.wasm
```
