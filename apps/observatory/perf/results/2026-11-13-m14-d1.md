## Experiments and controls

- **The drag's control** (`--control`, the same moves with no button): 0 frames drawn on either drag on both sides. Its first version ran the resize's moves along the header, where the next days' bands' hover drew 23 frames on each side; it runs in the cells now (`docs/DECISIONS.md`, "Measurement", 2026-11-13).
- **`domDrawn` against `domPainted`** for TanStack's select drag at the reference: 63.1% and 63.6% drawn by `domDrawn` over two runs, 98.3% by paint. In a dumped trace, every frame but one committed (style, layout, and paint), a third of them in 0.55–0.9 ms of animate; the one idle frame (0.58 ms) painted nothing.
- **The copy's control:** the sheet's first key set `contender:copy-declined` alone within 500 ms, the state declined, 0.29–1.67 ms after the key, on both sides and both profiles.
- **Page reads by request:** counted as data requests, the week and the sheet read 0, since DuckDB's reads are its worker's synchronous XHRs. By the worker's messages, 8 each on both sides, the block 0.
- **The A/B smoke** (one round, `rows-20`): the pipeline ran, merged, summarized, and paired, and the files name their build, their merged runs, and one date. One round is no reading, and two said opposite things. Before the fixes, TanStack's grown level drew 37.7 / 24.0% (down / sideways) against the kept level's 52.9 / 62.5%; after them, 36.7 / 46.7% against 31.4 / 37.5%. GPUI drew 100% on both, its work 0.4–1 ms more on the grown level both times. D2's 10 rounds decide whether either moved.

## The review's fixes

`/code-review high` on D1's code found ten things; all fixed before the rerun:
- `ab.ts` paired a run that recorded a failure; it leaves it out and names it now, and the merged file says how many runs it holds.
- `ab.ts` passed `--stop all` by default, which would run the copy at every stop; without `--stop` each metric's own stops run.
- `ab.ts` had its own interpolated IQR; it uses `protocol.ts`'s, the quiet-machine gate's.
- `ab.ts` buffered each child's output (1 MiB, then killed) and showed nothing until it ended; it streams through now.
- A GPUI drag frame with two drawing rAF callbacks counted twice; each main frame counts once.
- `ab.ts` took a merged file's header from TanStack's run when GPUI's was missing, claiming the tree's gpui-kit; it claims none then.
- `coveredPct` ran to the trace window's end, 100 ms past the scroll's rest; it runs to the rest.
- The drag's select path was checked only within one process, which an A/B's one-run invocations never share; it's each run's `workload` now, and `ab.ts` pairs a round only where both builds did the same work.
- Files took a UTC date, so an evening A/B split across two days; every file `runMetric` writes takes the local date, and `ab.ts` passes one `--date` to all.
- `ab.ts`'s header named a milestone's results file; it names the method.
