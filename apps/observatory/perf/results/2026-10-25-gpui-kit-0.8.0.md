# Dependency upgrade: gpui-kit 0.7.3 → 0.8.0 (2026-10-25)

Measured on Apple M1, Darwin 25.6.0, machine `local`, by `just observatory check` (no JSON written: its parts run without `--label`). Load average ~3–5 through it. What changed and why: `apps/tycho/perf/results/2026-10-25-gpui-kit-0.8.0.md` (the lock, wasm-bindgen 0.2.127, the source checks).

## What changed

- The GPUI contender's wasm: **2697.8 → 2707.9 KiB brotli (+10.1 KiB, +0.4%)**, against a 0.7.3 build from a worktree. No code changes. The TanStack contender and the page don't build gpui-kit.
- `theme.css` (the TanStack contender's, generated from gpui-kit's resolved default theme): only its version line changed; every color is the same.

Everything else in `check` passed: `sizes --check` (the panel-leak check), the placeholder against the first frame (light/dark, DPR 2 and 1), `reach` (End = `count(*)`, the contract, the probe key and its control, replay, relay), `engine-files --controls`, `tanstack-view --gpui` (the GPUI contender's column widths unchanged), `tanstack-contract`, `tanstack-parity` (keys, Shift+wheel, track press, drag settle, tooltip, focus, in Chromium, Firefox, WebKit, the GPUI contender's keys the same), `page --check`, and the fixtures (paging, SQL, the TanStack run, `cell-fixture --check`: 254 cells, budgets unchanged).

Not run: the per-use metrics (`metric …`), `readout-cost`, the throttled cold run. The published comparison's numbers are still 0.7.3's.
