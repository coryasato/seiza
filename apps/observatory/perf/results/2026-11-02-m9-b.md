# M9 part B: the wide sheet's data file and the GPUI contender at the level (2026-11-02)

Measured on Apple M1, Darwin 25.6.0 arm64, machine `local`, Chromium 153 headless=new, 1440×900 at DPR 2. The cold runs are the protocol's (median of 10, reference and throttled); the rest are checks, not measurements. Load average 3.6–4.4 (the machine in use).

Raw:
- `2026-11-02-gpui-cold-wide.json`: the wide build's cold load (`cold.ts --level wide --write-baseline`), its level, features, and versions recorded.
- `2026-11-02-m9-b-wide.json`: `perf/wide.ts` at each stop and the failed loads.

## What changed

- **The data:** `data/prep.ts` builds the wide sheet's file, `ghcn-2025-tmax.parquet` (`prep-ghcn.sql`), from GHCN-Daily's sources kept in `data/raw/ghcn/` and pinned by SHA-256 in `MANIFEST.json`, beside the asteroids (unchanged: same SHA-256). 10,632 rows, 368 columns, 6,667,056 B (6.36 MiB), 6 row groups, highs −75.5 … 51.1 °C, SHA-256 `d7ad70c3…1da7`. `MANIFEST.json` holds its license (CC0 1.0), credit (cut from NOAA's data, not NOAA's unaltered data), citation (GHCN-Daily 3.35, accessed 2026-11-02), version (3.35-upd-2026103117), sources, and range.
- **The hosting:** the Worker keys each data file by its own SHA-256 (`DATA_FILES`), staging copies every file `MANIFEST.json` names, and `worker-check` checks each.
- **The scenarios:** `contenders/scenarios.ts`, the one list (Big file on the base level, the wide sheet on the `wide` level, its four stops); `contenders/paths.ts` gives a level a base under its contender's.
- **The GPUI contender at the level:** the crate's feature `wide` (the table's and the bridge's `custom-cells`, `pin`, `density`), built into `web/dist-wide/` at `/observatory/contenders/tall-table/gpui/wide/`; `scene.rs` (the file, the stop's density, Station and Place pinned, heat on every day through the file's range); `?scenario=` and `?stop=` resolved by the JS host, an unknown id failing the load.
- **Wasm (brotli, `sizes.ts`'s measure):** the base 2,768.1 → 2,768.2 KiB (the scene's code; no level code in it); the wide level 2,773.3 KiB, +5.1 over the base (after the review's fixes; 2,775.0 at the baseline's run). Tycho and the table's bare host don't build the contender's crate: unchanged. `shared-web/perf/`'s `machineInfo()` now records `versions` in every app's results files; no wasm.
- **The fixtures:** `cells.json` and `sql.json` gain a `scenarios` section (the GHCN file's cells at the default stop's budgets; its page SQL and summary); the table's native cell test and the engine's SQL test read each section (test code only).

## The review's fixes

`/code-review high` found ten; seven fixed here, one cleanup, two left for market watch (the second feature level): `cell-fixture.ts`'s ports and columns per scenario, and `stage.ts`'s levels, each written for the wide level alone.
- `ghcnd-version.txt` pinned with the three sources (its version is in the file's metadata and citation); control: today's version file in its place fails the build.
- The heat's range drops a day's NULL min and max instead of reading them as 0 (no such day in today's file: the range is unchanged).
- The harness checks the level's own data files before serving it; control: the wide build without the GHCN file fails at once, naming `just observatory data`, and the base still serves.
- The level reaches Vite as its mode (`--mode wide`; `preview({ mode })` from the harness, a `shared-web/perf/serve.ts` option), never through the environment.
- After a failed load the replay's open, fling, and jump reject at once (`wide.ts` checks it at each failed load), and the host marks the failure again if asked to open.
- The Worker parses `DATA_FILES` once an isolate and answers a malformed one with a 503 (`{not json` and a non-hash value: 503 under `wrangler dev`).
- `wide.ts` reads the file's path through the harness, quotes escaped.

## The data, checked

- **Rebuilt from A1's pinned downloads,** the file matches A1's `ghcn-2025-tmax-double.parquet` in every value (`EXCEPT ALL` both ways: 0 rows), row order (station and latitude by row number: 0 differences), and column names; it differs only by its `KV_METADATA` credit (+209 B).
- **The pin's control:** one hex digit of the stations file's pin changed in `MANIFEST.json` fails the build, naming `--repin`.
- **NOAA's year file has moved since A1:** 166,428,414 B at 01:07 UTC on 2026-11-03 (the bucket's `Last-Modified`), against the pinned 166,428,453. The bucket has no versioning. The pinned bytes are in `data/raw/ghcn/` on this machine only.
