The fixtures that say what "the same" means for a DOM contender (root `CLAUDE.md`, "Comparison protocol"), in `components/tall-table/fixtures/` (formats: its `README.md`), each run natively with negative controls. Apple M1, Darwin 25.6.0 arm64, machine `local`; the cell fixture's page in Playwright 1.63.0's Chromium (headless=new).

Raw: the fixtures themselves (`components/tall-table/fixtures/paging.json`, `cells.json`, `sql.json`); `just observatory check`'s run is summarized below.

## What changed

- **The fixtures and their tests.** `paging.json` and `cells.json` run in the component (`src/state/fixtures.rs`, a child of `state`: GPUI's test app, its clock, the state's own scroll, drag, and paging paths); `sql.json` in the DuckDB engine, where the SQL is written (`crate/src/tall_table.rs`). `just observatory fixtures` runs them, and `check` now ends with it.
- **The GPUI contender's cell probe:** with `?cells` the table probes its cells and the contender publishes `__contender.cells` and `__contender.columns` (`docs/contender-contract.md`, "The cell probe"); `perf/cell-fixture.ts` writes `cells.json` from them, and `--check` compares. `reach` checks neither is published without `?cells`. Its wasm: 2,697.1 KiB brotli, +1.7 KiB on part B's baseline (2,695.4): the cell probe's code links now that it can be on.
- **The component:** `shown_text` (what a loaded cell shows) split out of `render_body` for the cell fixture, inlined back; dev-dependencies on gpui-kit's `test-support`, `futures`, and `serde_json` (`Cargo.lock`: 29 packages added, none moved). Tycho's wasm within build jitter: Tycho's [`2026-10-17-observatory-m2-c.md`](../../../tycho/perf/results/2026-10-17-observatory-m2-c.md).

## Experiments and controls

- **Paging controls**, each a `Paging` field moved one way, each must fail at least one scenario, and did: scroll settle 0 ms (6 scenarios fail; the lean-ahead cancelled in the same step) and 500 ms (3: no cancel at 250 ms), drag settle 0 ms (2: the drag loads at once) and 160 ms (1), prefetch 1 and 3 (7 each), 2 and 4 reads in flight (3 and 1), 512-row pages (7), a 128 MiB cache (1: page 2 survives the budget). A broken expectation (`load 1378` for `load 1377`) fails at its step with both lists.
- **Cell controls:** a float's `Display` text (no `.0` on a whole number, as JS's `toString`) fails 15 drawn cells (`8` for `8.0`, `-2082` for `-2082.0`, …); the budgets a character smaller or larger pass every drawn cell (nothing on this data is near 12 characters) and fail 6 and 8 rounding cases.
- **SQL controls:** the first page by `LIMIT 1024 OFFSET 0` (the same rows, another query), the same query with a line break, and sending the keyed metadata query too: each fails.
- **Every expected request was worked out by hand first** (the `why`s in `paging.json`), then run: all matched the table, and so did the 11 rounding cases.
- **Tycho's wasm and the split function:** `shown_text` as a call cost Tycho 219 B raw; `matches!` instead of `==` for the NULL test changed nothing; `#[inline(always)]` brought it to −36 B raw, +20 B brotli.

## After the code review

A review found, and this fixes: `cell-fixture.ts` turned an unreadable `cells.json` into no `rounding` cases and would have written it so (it now fails without them); its "longest text" pick used DuckDB's text for a double, not the table's (it now scans every value of each column with Rust's `{:?}` rule, checked against every drawn `exact`: the longest is 8 characters, in `a`, so nothing in the file rounds, now over the whole file); its value check failed on NaN and infinities and accepted FLOAT columns the fixture can't hold (now compared as text, and FLOAT refused); the SQL fixture's test copied `open_parquet`'s "two queries without keys" instead of testing it (`summary_queries` now returns the queries to send, and `open_parquet` sends exactly those); `paging.json` could leave out a field or misspell a control's and still pass (each now an error); `reach` checked only `cells` in a measured run (now `columns` too); `just observatory fixtures` says to build first. `serde_json` is a workspace dependency. `cells.json` came out byte for byte the same. After the fixes: the component's 33 and the engine's 20 tests, clippy on wasm32 and native, `just observatory lint`, `fixtures`, and `reach` pass. `open_parquet`'s change costs Tycho 423 B raw (Tycho's note).
