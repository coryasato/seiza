# The fixtures' window tests (`src/state/fixtures/`)

Each feature's fixture run natively in a window of GPUI's test app, children of `src/state/fixtures.rs`. Claude Code loads this file when a file under `src/state/fixtures/` is read. The table's rules and the map of its folders are in `components/tall-table/CLAUDE.md`, the repo's in the root `CLAUDE.md`; both apply here. `src/CLAUDE.md` and `src/state/CLAUDE.md` load with it. Paths are relative to `components/tall-table/`.

## Architecture

- **`src/state/fixtures.rs`**'s children: `src/state/fixtures/paint.rs` (with `custom-cells`) draws the paint fixture in a window of the test app and reads the cell probe, in the light theme and then the dark; `src/state/fixtures/live.rs` (with `live`) draws re-reads in a window on the paging scenarios' scripted delegate, whose values say which read is on screen, and checks `Refreshed` and the old rows drawn meanwhile, a grown last page among them; `src/state/fixtures/flash.rs` (with both) draws flashes over a source whose values each test sets, on the test clock (`advance_clock`), and runs `paint.json`'s `flash` section and its controls; `src/state/fixtures/follow.rs` (with `follow`) draws following in a window on the scripted delegate: the reader's moves, the host's `let_go` (the view held, the events once per change, a closed table, a drag's release deciding after it), the tail pin as rows arrive and reads land, `Following` and `TailDrawn`; `src/state/fixtures/resize.rs` (with `resize`) runs `cells.json`'s `number_px` and `resize` section and its controls, and drives the bands with the pointer in a window (`simulate_event`) over rows answered from memory: the drag, the held scroll, the fit, and the events; `src/state/fixtures/sort.rs` (with `sort`) clicks `sort.json`'s cycle through each kind's arrow in a window (its control too) over a source that answers at once or when a test says and logs its reads, cancels, and sorts, and checks what the fixture doesn't pin: the arrows in each state, glyphs and icons, the presses beside `select`'s and `resize`'s, the widths, the refusals (a source with the default `sort` among them), and what an accepted sort does; `src/state/fixtures/select.rs` (with `select`; Cmd+C and Ctrl+C bound only with `copy`) runs `selection.json` and its controls through the element (`TallTable` in a host view with an Escape binding of its own, so the keys go through the contexts) in a window sized to the fixture's view, and checks what it doesn't pin: the events and frames asked for, the tooltip, Escape's propagation, the drawing (`SelectState`'s `drawn`, tests only), `follow`, and a fill under the tint; `src/state/fixtures/density.rs` (with `density`) runs `density.json` against `Sizes` and `layout_columns` with its controls, and draws the density in a window over rows answered from memory, logging the reads: `set_density`'s fit before a frame and the top row kept, the page come into view read, following (the tail kept, a move's direction weighed at the row), the header, the gutter, the hit test, the tooltip's cut test at the scaled padding at a small and a large text, the clamp, the default at the web's rem and at 20 px, a set width, and with `resize`, `sort`, and `select` a drag and a fit, the arrows, and the tint at a short row; `src/state/fixtures/format.rs` (with `format`) runs `cells.json`'s `format` section against `ColumnFormat` and `shown_text` with its controls, and draws formatted columns in a window over rows answered from memory (a page answering 3 decimals every fourth row): the column's decimals and the page's, a fallback, an integer grouped, an unformatted float and a text column given a format as the base draws them, the tooltip (open for a rounded and a fallen-back cell, closed for a dressed one), `set_columns` with a new suffix, the feature on with no format as the base, with `resize` a fit, with `resize` or `density` a narrow set width, and with `density` the fit at 8 and 24 px text; `src/state/fixtures/copy.rs` (with `copy`) runs `copy.json` and its controls through the element in a window (the table opened at 0 rows and given its rows once the window has its size, so only the first page is read; Cmd+C through the keys' contexts, the host's `copy` as a host calls it) over the fixture's sources, each read answered at once and counted, the test app set up once a test and each case's window closed after it; `src/state/fixtures/reorder.rs` (with `reorder`) runs `reorder.json`'s move cases against `Move` (the selections with `select`) and its gap cases against `gap` (the pinned ones with `pin`, the run from `pin::in_effect`) with its controls, and draws the order in a window over rows answered from memory (`TallTable` in a host view with an Escape binding of its own), each cell's text its row and column's index; the drag through the pointer (`simulate_event`): under 2 px nothing, past it the preview and the line at the gap in the header and body at any height, no frame for a move that moves neither, no hover, the release at a gap and beside the block, a wheel moving the gap, Escape going no further, and with `select` the range rule, with `resize` the band's press, with `sort` the arrow's, with `pin` the pin and unpin across the edge; and each drawn cell its column's own at its place's left, a move reading nothing, the tooltip, `set_columns`, `set_order`'s refusal, `ColumnsMoved` once a change, the sideways scroll kept, and with `resize` the fit and the widths by index and a drag held on its column through a move, with `select` the range followed and `Selected`, with `pin` the count across the edge, `set_order`, and the cap, with `sort` the sort and its arrow on their column, with `copy` a copy's columns as it started, with `live` and `custom-cells` a flash on its cell; `src/state/fixtures/pin.rs` (with `pin`) runs `pin.json` against the geometry's own functions with its controls, and drives the pin in a window (a shell view that subscribes as it makes the table, so the first frame's `Pinned` is heard): the cells under a sideways scroll, the scroll and its range, the thumb, the edge line, the hover and tooltip, the cap, `set_columns`, and with `resize`, `select`, `sort`, and `custom-cells` what each does with it.
