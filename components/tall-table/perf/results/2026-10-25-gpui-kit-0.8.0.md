# Dependency upgrade: gpui-kit 0.7.3 → 0.8.0 (2026-10-25)

Measured on Apple M1, Darwin 25.6.0, machine `local`. What changed and why: `apps/tycho/perf/results/2026-10-25-gpui-kit-0.8.0.md` (the lock, wasm-bindgen 0.2.127, the source checks). No code changes in the table, the bridge, or the host.

## What changed

- The bare host's base build: **2677.7 → 2689.3 KiB brotli (+11.6 KiB, +0.4%)**, against a 0.7.3 build from a worktree. None of it is the table's: gpui-kit's own changes.
- 0.8.0's scrolling changes (the bounce engine, nested scroll areas no longer scrolling together) don't reach the table, which owns its scrolling and scrollbars; it uses only `Scrollbar::width()` from gpui-kit's scroll module.

## Checks

- `just tall-table test`: every feature off, each on, all on. PASS (the paging, cell, paint, and live fixtures among them).
- `just tall-table size`: no engine or panel linked, no feature's symbols in the base (`paint` 0 vs 24 with `custom-cells`, `take_refreshed` 0 vs 6 with `live`). PASS.
- `just tall-table smoke` (the base build): both shapes load, fill, and scroll in Chromium (WebGPU), Firefox (WebGL2), and WebKit (WebGPU). PASS.
- Not run: `perf` (frame work) and `live`.

## Reproducing it

```sh
just tall-table test
just tall-table build && just tall-table size && just tall-table smoke
```
