# M19 part C: `hide`'s cost and the close (2026-11-18)

Measured on Apple M1, Darwin 25.6.0 arm64, machine `local`: the wasm's bytes (the bare host's builds, every feature with and without `hide`, and each app that builds the table), the wide shape's frames with half its columns hidden (Chromium 153 headless=new, 1440×900 at DPR 2, cold, median of 10, the reference run alone: a hide changes what's laid out, not how a frame draws, so the reference run separates it), and the smoke check in three browsers. On part B's final table code (reviewed); part C changed no shipped code. Load average 2.4 at the start, after the session's earlier builds.

Raw: `2026-11-18-m19-c-size.json` (`just tall-table size --label m19-c-size`); frames, each `-reference.json`, run in this order, each build just before its run: `2026-11-18-m19-c-frames-base`, `-hide-none` (the `hide` build, nothing hidden: the control), `-hide` (the same build, `--hidden 2`: every other column hidden, 250 of 500), `-base-again` (the base at the end, for its spread across the session).

## What changed

Part C changed no shipped code. `perf.ts` gained `--hidden <n>` (the host's `?hidden=`, the flags and widths checked at open), and `harness.ts`'s `visibleColumns` skips a column at width 0, so the visible cells count the shown ones. The smoke check gained a hide run in a `hide` build (C2, below), with `hideThrough` in `perf/harness.ts`. After the code review, before the smoke runs below were repeated: the cell checks after the wheel read a frame from its row on, `reorder`'s exact values count, a column moved by a fractional width isn't compared by pixels, the pin checks need the whole default run at open, and `perf.ts` refuses `--hidden 1` (every column). None changes what the frame runs measured.

## Reproducing it

```sh
just tall-table size --label m19-c-size
just tall-table wasm release custom-cells,live,follow,resize,select,copy,sort,pin,density,format,reorder,clicks,group-headers   # and again with ,hide
just tall-table build && just tall-table perf --shape wide --profile reference --label m19-c-frames-base-reference
just tall-table build hide && just tall-table perf --shape wide --profile reference --label m19-c-frames-hide-none-reference
just tall-table perf --shape wide --profile reference --hidden 2 --label m19-c-frames-hide-reference
just tall-table build hide && just tall-table smoke
just tall-table build hide,pin,sort && just tall-table smoke
```
