# M15 part E: reorder's cost, the scripts' runs, and the gpui-kit 0.9.1 bump's frame work (2026-11-13)

Measured on Apple M1, Darwin 25.6.0 arm64, machine `local`, Chromium 153 headless=new, 1440×900 at DPR 2, cold (root CLAUDE.md, "Measurement protocol"): every run a median of 10, reference and throttled (CPU 4×, Fast 4G). On part D's final code (reviewed), no code changed in this part. A quiet machine (browsers closed): load average 1.8–2.9 over the perf runs (the builds before them pushed it to ~6).

Raw: `2026-11-13-m15-e-size.json` (`just tall-table size`); frames, each `-reference.json` and `-throttled.json`: `2026-11-13-m15-e-frames-base` (the base), `-reorder` (the `reorder` build, the list's own order), `-reorder-reverse` (the same build, `--order reverse`), `-base-0.9.0` (the base at gpui-kit 0.9.0), `-resize-select` and `-resize-select-0.9.0` (a `resize,select` build at each version, for the drags). Run in this order: base, `reorder`, reversed, base 0.9.0, `resize,select`, `resize,select` 0.9.0 at the reference run, then the same six throttled.

**The 0.9.0 builds:** the base and `resize,select` built at `a53c5ab` (the commit before the bump, `6bff554`) in a worktree with its own `target/`, their `dist/` served in place of this tree's by the same `perf.ts`. `perf.ts` records gpui-kit from the tree's lock, so those four files said 0.9.1; corrected to 0.9.0 by hand, with `protocol.servedBuild` naming the commit.

## Reproducing it

```sh
just tall-table size --label m15-e-size
# the 0.9.0 builds, in a worktree at a53c5ab: just tall-table build; just tall-table build resize,select (each dist/ kept)
just tall-table build && just tall-table perf --label m15-e-frames-base-<profile> --profile <profile>
just tall-table build reorder && just tall-table perf --profile <profile> [--order reverse] --label m15-e-frames-reorder[-reverse]-<profile>
just tall-table build resize,select && just tall-table perf --profile <profile> --label m15-e-frames-resize-select-<profile>
# a 0.9.0 dist/ copied into host/web/dist, then: just tall-table perf --profile <profile> --label m15-e-frames-<build>-0.9.0-<profile>
```
