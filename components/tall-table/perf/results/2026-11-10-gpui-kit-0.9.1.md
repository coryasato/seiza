# Dependency upgrade: gpui-kit 0.9.0 → 0.9.1 (2026-11-10)

Measured on Apple M1, Darwin 25.6.0, machine `local`. What changed and why: `apps/tycho/perf/results/2026-11-10-gpui-kit-0.9.1.md` (the lock, gpui-pre 0.3.12, the source checks, the A/Bs).

## What changed

- No code changes. gpui-pre-web 0.3.12's source is 0.3.11's; nothing the table calls changed its signature. No change to the paging, so no soak. But gpui-pre 0.3.12 resets the cursor on every mouse and scroll event, a write to `document.body.style.cursor` each time on the web (`apps/tycho/perf/results/2026-11-10-gpui-kit-0.9.1.md`): a wheel's, a scrollbar drag's, and `resize`'s and `select`'s drags' frame work may move, unmeasured here; M14's cost check reads it (`PLAN.md`).
- The bare host's base build: **2749.4 → 2753.6 KiB brotli (+4.2 KiB, +0.2%)**, raw after wasm-opt 9841.0 → 9809.1 KiB, against a 0.9.0 build of the same tree with the bump stashed. None of it is the table's: the GPUI contender's split puts it in gpui-kit's framework code (+3.0 KiB), the component flat (`apps/observatory/perf/results/2026-11-10-gpui-kit-0.9.1.md`).
- Each feature's own cost against the base: `size`'s, in `2026-11-10-gpui-kit-0.9.1-size.json`.

## gpui-kit 0.9.1's DataTable, against the table's features

Read from gpui-component 0.9.1's `src/table/` against 0.9.0's.

- **`ColumnFixed::Right` (#3833):** `Column::fixed_right()` pins the trailing columns; the scrolled columns are the range between the left and right runs (`scrollable_cols`), each run drawn in its own header and cell blocks with its border on its inner edge, a drag-to-move refused across either run's edge, and the first right-pinned column's resize band dropped (its edge wouldn't follow the pointer, since the run stays put). The table's `pin` is left-only (a count of leading columns), and PLAN's "Beyond `DataTable`" lists right-pinned columns as a TanStack candidate; `DataTable` now has it. The one change here that maps to a feature the table could add.
- **Tab and Shift+Tab leave a focused DataTable (#3800):** it no longer binds them to the next and previous column. The table never bound Tab, so focus already leaves it: nothing to carry over.
- **A selected cell's border, distinct from hover (#3866):** a selected cell gets a 1 px `table_active_border` edge over its `table_active` fill; a right-clicked one keeps the half-opacity edge. The table already edges its active cell 2 px while focused, over the range's tint, which is edged too (README, "Selecting"): nothing to carry over.
- **Rows named after their cells (#3773):** `TableDelegate::row_label`, by default the row's `cell_label`s joined with commas, set as the row's `aria_label` when the window's accessibility is active. gpui-pre-web has no accessibility tree (0.3.12's source has none), so on the web nothing reads it; the table's a11y gap (README, "Canvas tradeoffs") stays the DOM mirror's to close.
- **A header's default name centered in a set header height (#3731):** `render_th`'s default is now `w_full` rather than `size_full`, and with `header_row_height` set and no paddings the cell drops its vertical padding. The table draws its own header text, its height following the row's (`density`): nothing to carry over.
