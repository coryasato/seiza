Measured on Apple M1, Darwin 25.6.0 arm64, machine `local`, Chromium headless=new, 1440×900 at DPR 2, cold, median of 10, reference and throttled (CPU 4×, Fast 4G) (root CLAUDE.md, "Measurement protocol"), on the final build (`6b74ade`, no change to the table in this part). The machine quiet (browsers closed); load average 1.2–1.8 over the perf runs, up to 4.7 for a minute after each build's compile, falling.

## A copy near the cap, and a scroll during one (D1, C2's numbers)

`just tall-table copy`: a copy of 0.9 of the 64 MiB cap from a cold view (narrow: 477,052 rows of 11 columns, 126.6 bytes a row; wide: 6,166 rows of 500, 9,794 bytes a row; 57.8 and 57.6 MiB), then the steady scroll of `perf` alone and the same during a copy, each window ending at the scroll's rest. Median of 10:

| | Narrow ref | Narrow throttled | Wide ref | Wide throttled |
|---|---|---|---|---|
| Key → copied | 1,614 ms | 2,360 ms | 1,619 ms | 2,409 ms |
| Key → written | 1,734 ms | 2,798 ms | 1,745 ms | 2,838 ms |
| Rows a second | 296 k | 202 k | 3.8 k | 2.6 k |
| Wasm heap before → after | 13.69 → 13.69 MiB | same | 26.94 → 33.94 MiB | same |
| Scroll alone: work p50 / p95, late | 5.97 / 7.21 ms, 0% | 20.46 / 27.82 ms, 27.4% | 6.93 / 8.23 ms, 0% | 25.10 / 35.55 ms, 54.2% |
| During a copy: work p50 / p95, late | 5.31 / 5.66 ms, 1.2% | 19.61 / 22.71 ms, 42.9% | 6.34 / 7.82 ms, 1.3% | 23.61 / 30.55 ms, 55.2% |
| Outside frames, alone → during | 27 → 779 ms | 77 → 856 ms | 31 → 602 ms | 82 → 616 ms |
| Scroll to rest, alone → during | 2.12 → 2.59 s | 2.20 → 2.26 s | 2.13 → 2.32 s | 2.22 → 2.25 s |
| The scroll the copy ran through | 78% | 100% | 73% | 100% |

- **~58 MiB on the clipboard in 1.7 s at reference, 2.8 s throttled,** in either shape: the bytes, not the rows, set the time (296 k narrow rows a second, 3.8 k wide). Key → written adds 0.12 s at reference and 0.44 s throttled over key → copied: the Blob built from the pieces and the browser's write.
- **The heap grows by no more than the reads in flight and a piece.** The wide shape's 7.0 MiB is its two reads beside the cache (`background_limit` at `max_in_flight` 3: 2 × 1,024 rows × 500 floats × 8 bytes, 7.8 MiB) and a piece (~16 k cells, ~0.3 MiB of text); the narrow shape's pages (11 columns) fit in memory the wasm had already grown to, so its heap doesn't grow. Wasm memory never shrinks, so "after" is the copy's high-water mark; the copy's 58 MiB of text is never in it (each piece dropped once sent, the strings JS's).
- **A scroll during a copy keeps its per-frame work and loses frames.** The copy's turns run as tasks between frames, ~0.6–0.8 s of them in a ~2.3 s scroll. At reference that's 1.2–1.3% late frames against none, and the narrow scroll took 0.47 s longer to rest (the copy ran through 78% of it). Throttled, the narrow scroll's late frames rose from 27% to 43%; the wide scroll was already 54% late alone, and the copy added 1 point. Per-frame work reads *lower* during a copy (5.31 against 5.97 ms narrow, as in part C's run); the trace's frames don't count the copy's turns, which run outside them.
- **Against part C's one run:** within ~10% (key → written 1.73 s against 1.64 narrow), the throttled late frames now 27% and 43% against 42% and 53%: one run each then, the median of 10 now.
