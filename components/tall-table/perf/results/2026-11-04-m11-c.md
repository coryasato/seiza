# M11 part C: the cells' text from one element, measured, and the close (2026-11-04)

Measured on Apple M1, Darwin 25.6.0 arm64, machine `local`, Chromium headless=new, 1440×900 at DPR 2, cold, median of 10 (root CLAUDE.md, "Measurement protocol"), on the final build (`15ed4dc`, no change to the table in this part). The machine was quiet (browsers closed): load average 1.5–3.7 over the runs, highest just after a build. After the code review, a second quiet set (21:37–21:46, load 2.0–3.2) measured the parent throttled and its flash at the reference run, and ran the reference flash again; and the parent's feature builds and each app's wasm were sized (no quiet needed).

**What was measured, and what wasn't** (decided with the user this session, [`docs/DECISIONS.md`](../../docs/DECISIONS.md), "Features", 2026-11-04, M11 part C): the final build in full (the flash's feed, the base's frame work both profiles); M11's parent (`d96547f`: this tree with `src/` checked out at it, so the perf scripts are the same) in both profiles, and its flash at 1k updates/s in both; and the features whose drawing goes through the cells' text (`custom-cells`, `pin`, `density`) re-read at the reference run. `resize`, `select`, `copy`, `sort`, `live`, and `follow` draw bands, tints, headers, or nothing a frame of their own and were not re-read: their rows keep their numbers, read on the earlier base. The quiet windows were ~60 minutes together.

Raw: `2026-11-04-m11-c-live-<rate>[-flash]-throttled.json` (`live.ts` at 100, 1k, and 5k updates/s, with and without `--flash`, the `live,custom-cells` build), `-live-1000-flash.json` (the reference run), `-live-1000-flash-throttled-parent.json` and `-live-1000-flash-parent.json` (the parent's), `-rerun-live-1000-flash.json` (the reference flash again); `-frames-base.json` (`perf.ts`, both profiles), `-frames-parent-reference.json`, `-frames-parent-throttled.json`, `-frames-custom-cells-heat-reference.json` (`--cells heat`), `-frames-pin-reference.json`, `-frames-density-reference.json` (the host's dense default, 18,11,56); `-size.json` (`size --against d96547f`), `-size-parent.json` (`size` with the parent's `src/`).

Nothing in this part. Part B's element (each region's loaded cells' text drawn by one element, every glyph in one layer) is what's measured.

**C1 passes:** with the flash, no late frame at any rate, as without it (0% in every run of every set); its work a frame, 7.6–8.6 ms throttled, half the parent's 16.4 ms, and at the reference run 4.5–4.6 ms against the parent's 5.52 (−17%). The main thread is still busier with the flash (every frame drawn, ~520–590 ms a second against ~310–340), but no longer saturated (the parent's 994), and the feed lands twice as many batches (30 refreshed frames a second against 14.8). The reference set's latency spread is 13.4%, and 15.0% run again: each time one run reads ~1.5 ms below the rest (10.9 and 10.8 ms against 11.7–12.6), while the two sets' medians agree within 0.5% (12.42, 12.36 ms; work 4.59, 4.52). The spread is a run's, not the machine's. At the reference run the update → refreshed latency is ~1 ms longer than the parent's (12.4 against 11.3 ms p50); C1 doesn't gate it, and it's recorded here as found.

## Reproducing it

```sh
just tall-table build live,custom-cells
for rate in 100 1000 5000; do
  just tall-table live --rate $rate --profile throttled --label m11-c-live-$rate-throttled
  just tall-table live --rate $rate --flash --profile throttled --label m11-c-live-$rate-flash-throttled
done
just tall-table live --rate 1000 --flash --label m11-c-live-1000-flash
just tall-table build && just tall-table perf --label m11-c-frames-base
git checkout d96547f -- components/tall-table/src && just tall-table build
just tall-table perf --profile reference --label m11-c-frames-parent-reference
just tall-table perf --profile throttled --label m11-c-frames-parent-throttled
just tall-table size --label m11-c-size-parent
just tall-table build live,custom-cells
just tall-table live --rate 1000 --flash --profile throttled --label m11-c-live-1000-flash-throttled-parent
just tall-table live --rate 1000 --flash --label m11-c-live-1000-flash-parent
git checkout HEAD -- components/tall-table/src
just tall-table build live,custom-cells && just tall-table live --rate 1000 --flash --label m11-c-rerun-live-1000-flash
just tall-table build custom-cells && just tall-table perf --cells heat --profile reference --label m11-c-frames-custom-cells-heat-reference
just tall-table build pin && just tall-table perf --profile reference --label m11-c-frames-pin-reference
just tall-table build density && just tall-table perf --profile reference --label m11-c-frames-density-reference
just tall-table size --against d96547f --label m11-c-size
```
