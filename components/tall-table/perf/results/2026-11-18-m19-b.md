# M19 part B: `hide` built and tested (2026-11-18)

Measured on Apple M1, Darwin 25.6.0 arm64, machine `local`. Bytes only: the bare host's release builds (`cargo build -p`, wasm-bindgen, wasm-opt with the apps' flags, brotli 11) for the base unchanged and `hide`'s symbols out of it; `hide`'s own bytes against the base, each app's, and the wide shape's frames are part C's (checks C1, C2). Natively: the random test's controls, the soak, every rule mutated, `pairs`; in Chromium, the bare host's hooks. Everything below but the hooks ran on the final code, after part B's three code reviews and their fixes.

Raw: `2026-11-18-m19-b.json` (`just tall-table size --against 0f6970b --label m19-b`: the base, each feature's build, the symbols, the base against M19's parent); in the gitignored `raw/`: `2026-11-18-m19-b-long.txt` (the mutations, `pairs`, the soak, the controls under `SEED`s 0–6, `size`, in one run), `2026-11-18-m19-b-control-counts-reverted-resize.txt` (the first sweep, which found the `resize` rule below), `m19-b-mutate.py` (the mutations), `m19-b-hide-host.ts` (the hooks in Chromium).

## What changed

- **The table:** Cargo feature `hide`: `TallTableColumn::hidden` and `is_hidden`, `set_column_hidden`, `set_hidden`, `TallTableEvent::ColumnsHidden`; a hidden column laid out at width 0 in its place (`layout_columns`), drawn nowhere (`visible_columns` in both builds, `Pin::visible`, the active cell's outline) and hit nowhere (`cell_clamped`'s fallback the last shown place); `select`'s keys stepping over it, a selection with no shown column cleared at a hide and by `set_selection`, nothing selectable with every column hidden; `copy` writing the shown columns; `reorder`'s gap among them; a held `resize` drag ended as its release; `ColumnProbe::hidden` (`src/state/hide.rs`; `docs/DECISIONS.md`, "Features", 2026-11-18).
- **The bridge:** `hidden` on each layout column and the flags on a global (`Publish::hidden`).
- **The bare host:** `?hidden=<n>` (every `n`th column hidden before the first frame) and, with `?perf`, `__tallTableHide(indices)` and `__tallTableHidden`.
- **The fixtures:** `hidden` cases in `pin.json` (3), `reorder.json`'s gaps (2), `group-headers.json` (2), `selection.json` (1 scenario), and `copy.json` (4), each fixture's control of them (`hidden-at-width`, `hidden-counted`, `key-onto-hidden`, `hidden-copied`); the TanStack contender's tests skip them by name.

## The random test's controls

31 controls, each run under `SEED`s 0–6 in the all-on build (48 cases a seed), `hide` among its features, its `Hide` steps placed last:

| Controls | Caught |
|---|---|
| `hide`'s: `DrawnHidden` (a `pin` control, invariant 21), `FlagByPlace` (18), `select`'s `HiddenSelectionKept` (15) | 21 of 21 |
| The 28 earlier controls, with the `Hide` steps placed | 185 of 196 |
| The same at M18's close, without them ([`2026-11-18-m18-b.md`](2026-11-18-m18-b.md)) | 187 of 196 |

The `Hide` steps cost three catches and give one: lost `GapOutsideParent` at `SEED` 5, `EndWithoutPlan` at 4, `HitIgnoresRun` at 6; gained `CloseKeepsReads` at 3. The misses there before (`GapOutsideParent` at 1, 3, 6; `IgnoreLoading` at 5, 6; `HoldingWithoutEnd` at 3, 4; `KeepOnReread` at 4) stay. A placed step forgets the state a control needs or reaches one it didn't, as the replaces did. `SEED` 0, which `just tall-table test` runs, catches every control; the soak reaches the rest. The random test itself passes at every `SEED` 0–6. The counts are the same before the code reviews' fixes and after.

**What it found:** the first sweep failed at `SEED`s 3 and 6 at invariant 12: a hide reverted a held `resize` drag's width with no event, after a `set_density` had told the host the drag's width (`Hide(13119626539869124705)` at step 86, and `Hide(16548018202603264344)` at step 38). The drag now ends as its release would (`docs/DECISIONS.md`, "Features"); found and fixed in the part, so no scenario test or exclusion was kept, and `a_resize_drag_ended` (`src/state/fixtures/hide.rs`) holds the rule.

## Experiments and controls

- **Every rule mutated:** 23 of `hide`'s rules (the layout at no width; the base's, `pin`'s, and the outline's drawing tests; `cell_clamped`'s fallback; the keys' step; the sideways scroll to a hidden column; `copy`'s shown columns, its `None` with none shown, `Declined`'s count; `reorder`'s gap; each drag a setter ends; the event once a change; `set_hidden`'s length refusal; the layout at the setter; a selection with nothing shown cleared at a hide and by `set_selection`; a plain key and a jump from a hidden active cell to the nearest shown column; the keys and a jump with every column hidden), each alone in the all-on build (the base's filter in a `hide` build, which draws without `pin`), each failing at least one window test or fixture. One first passed, before the reviews: `sort`'s pressed arrow forgotten, since the next frame forgets an arrow it doesn't draw; its test now reads the arrow inside the setter's update.
- **The fixtures' controls** (`hidden-at-width` in `pin.json` and `group-headers.json`, `hidden-counted` in `reorder.json`, `key-onto-hidden` in `selection.json`, `hidden-copied` in `copy.json`) each fail the cases they name, with `hide`; without it, their cases and controls are skipped.
- **`pairs`** (`hide` the 14th feature: 103 clippy builds, the 71 pairs with code gated on both, 103 rustdoc builds): passed, 30 min.
- **The soak** (`just tall-table soak`, `hide` among its features): 4 `SEED`s × 500 cases, passed, 99–104 s a `SEED`.
- **The bare host in Chromium** (`m19-b-hide-host.ts`, a `hide` release build from before the reviews' fixes, which changed no host behavior): in both shapes, `?hidden=2` lays every other column out at width 0, flagged in the layout probe (narrow 6 of 11 shown, wide 250 of 500), and none without it; `__tallTableHide([0, 2])` hides those two and shows the rest, `__tallTableHidden` and the layout agreeing, and `__tallTableHide([0.5])` is refused; no console problem.

## Reproducing it

```sh
just tall-table size --against 0f6970b --label m19-b

just tall-table soak

python3 components/tall-table/perf/results/raw/m19-b-mutate.py
just tall-table build hide && node components/tall-table/perf/results/raw/m19-b-hide-host.ts
```
