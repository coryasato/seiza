# Dependency upgrade: gpui-kit 0.8.0 → 0.9.0 (2026-11-02)

Measured on Apple M1, Darwin 25.6.0, machine `local`. What changed and why: `apps/tycho/perf/results/2026-11-02-gpui-kit-0.9.0.md` (the lock, gpui-pre 0.3.11, the source checks, the nightly).

## What changed

- One code change: gpui-pre 0.3.11 renames `ScrollWheelEvent` → `ScrollEvent` and the element's `on_scroll_wheel` → `on_scroll` (the old names deprecated). `state.rs` and `state/select.rs` take the new names; the select fixture's wheel builds the event with its new `source: ScrollSource::Pointer`. The state's own `on_scroll_wheel` keeps its name. No change to the paging, so no soak.
- The bare host's base build: **2689.6 → 2749.7 KiB brotli (+60.1 KiB, +2.2%)**, against a 0.8.0 build from a worktree. None of it is the table's: the GPUI contender's split puts the component at −0.4 KiB, the rest in gpui-kit's framework (gpui, wgpu 30, taffy 0.15) and static data (`apps/observatory/perf/results/2026-11-02-gpui-kit-0.9.0.md`).
- Each feature's own cost against the base is within 0.5 KiB of what it was (`size`: custom-cells +5.6, live +5.2, follow +8.1, resize +1.0, select +6.4, copy +17.2, sort +22.2, pin +3.1 KiB brotli).

## Checks

- `just tall-table test`: every feature off, each on, all on (the random test of the paging among them). PASS.
- `just tall-table size`: no engine or panel linked, no feature's symbols in the base (and the controls), no home path in any build (the control without `trim-paths`: 993). PASS.
- `just tall-table smoke` (the base build): both shapes load, fill, and scroll in Chromium (WebGPU), Firefox (WebGL2), and WebKit (WebGPU). PASS.
- Not run: `perf` (frame work), `live`, `follow`, `copy`, `sort`, the feature builds' smoke.

## Reproducing it

```sh
just tall-table test
just tall-table build && just tall-table size && just tall-table smoke
```
